# Ficha de Corrida

Projeto de uma ficha de inscrição para corrida, desenvolvido utilizando HTML5 e CSS3. A página permite que o participante preencha seus dados pessoais, escolha o gênero, a distância da corrida e itens adicionais que deseja receber.

## Sobre o projeto

Este projeto foi desenvolvido como uma atividade prática para exercitar conceitos fundamentais de desenvolvimento web, principalmente a criação e estilização de formulários.

A interface apresenta um formulário de inscrição contendo:

* Nome e sobrenome
* CPF
* Telefone
* Idade
* E-mail
* Seleção de gênero
* Escolha da distância da corrida
* Seleção de itens adicionais
* Botão para envio do formulário

## Tecnologias utilizadas

* HTML5 — estrutura da página e criação do formulário
* CSS3 — estilização, cores, espaçamentos e organização dos elementos

## Como executar

Não é necessário instalar nenhuma dependência.

1. Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/Ficha_corrida.git
```

2. Entre na pasta:

```bash
cd Ficha_corrida
```

3. Abra o arquivo `index.html` em qualquer navegador.

Também é possível abrir o projeto utilizando o Visual Studio Code e uma extensão como o Live Server.
